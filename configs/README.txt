Положите сюда файлы конфигураций AmneziaWG (*.conf).

Страна определяется по имени файла, а не по адресу сервера:
  Germany.conf, germany-2.conf, DE.conf, Deutschland.conf → Германия
  Japan.conf → Япония
  United Kingdom.conf, UK.conf, Great_Britain.conf → Великобритания
Неизвестные названия отображаются как отдельные профили.

Файл появляется в списке автоматически (или по кнопке «Обновить»). Удалили файл — запись исчезла.
Конфигурации содержат секретные ключи: не публикуйте их и не отправляйте третьим лицам.
